# Web Streaming - TEDI DIGITAL

Sitio web desarrollado para mostrar y promocionar servicios de streaming digitales.

## Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub
* GitHub Pages

## Estructura del proyecto

```txt
web-streaming/
│
├── assets/
│   └── img/
│
├── index.html
├── styles.css
├── script.js
└── README.md
```

## Sitio web

https://tedi-digital.github.io/web-streaming/

## Instalación local

Clonar el repositorio:

```bash
git clone https://github.com/TEDI-DIGITAL/web-streaming.git
```

Ingresar a la carpeta:

```bash
cd web-streaming
```

Abrir el archivo:

```bash
index.html
```

## Actualizar el proyecto

Después de realizar cambios:

```bash
git add .
git commit -m "Descripción del cambio"
git push
```

Los cambios se publicarán automáticamente mediante GitHub Pages.
